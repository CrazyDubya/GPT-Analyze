# GPT-Analyze

A macOS SwiftUI app for analyzing GPT conversation exports.

## What's here

- `GPT_Analyze/ContentView.swift`, `GPT_AnalyzeApp.swift` — the app.
- `GPT_Analyze.xcodeproj` — Xcode project; open and run.
- `COMMERCIALIZATION_ANALYSIS.md`, `EXECUTIVE_SUMMARY.md` — generated assessments of the idea, not documentation of the code.

## Status

Six commits, then restarted as `GPT-Analyze2` a month later with the same structure. Neither version got past the initial build. The working conversation-analysis code is in `conversation-analysis-tools`; these two are the abandoned desktop front-end for it.
